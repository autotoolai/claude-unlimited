## 2026-10-22

- **修掉教程页截图被压扁的真缺陷**：`.cu-shot img` 原来写的是 `width:100% + height:auto + max-height`，
  浏览器在限高时**不会回调宽度**——竖图（VS Code 插件面板 909×989、Cursor 扩展面板 930×1125）先被拉到
  600px 宽，再被限高压到 384px 高，盒子比例从 0.92 变成 1.56，画面被横向拉扁：字变宽、行距压扁、
  界面文字糊成一片。build、check:css、check:theme、typecheck 全都查不出来，因为每条规则都"正确"，
  错的是浏览器怎么把它们合起来算。改成 width/height 都交给 auto、只留 max-width 与 max-height 两个上限，
  浏览器按固有比例换算，图片不再变形。限高同时从 24rem(384px) 抬到 34rem(544px)：竖图靠高度上限决定
  显示尺寸，384px 下只剩 353px 宽、界面文字太小；544px 下 VS Code 那张显示为 500×544。
  这次修的正是设计规范里早就写着的那句「≤1.2 的竖图只受高度上限约束」——之前 CSS 与规范不一致，规范是对的。
- **新增 `npm run check:shots` 截图几何门禁**：扫全部场景页的每张图，比对横向与纵向的缩放系数，
  差超过 2% 就判失真并报错退出。抓的是「只有肉眼才看得出、其它门禁都查不出」这一类缺陷。
  加完立刻在 44 张图上跑通。
- **密集界面图补上可点开原图**：23 张表单 / 面板 / 弹窗 / 对话界面图加上 `zoom: true`，
  渲染成可点的链接，点开在浏览器里看原图——这些图在版心里只有 0.28~0.55 倍，界面文字偏小是客观事实。
- **Cursor 扩展面板配图**：新增 `/guide/cc` 的 Cursor 一节配图——取自卖家腾讯文档《AI工具使用教程》
  的「图 10 cursor 官方 cc 插件」，内容是 Cursor 扩展面板里搜到 Claude Code 官方扩展、
  右侧点 Install 的样子。原图 3120×2007 是 2 倍 retina 截屏，降到 1 倍（1560×1003）
  后显示效果不变、文件从 273KB 减到 124KB。

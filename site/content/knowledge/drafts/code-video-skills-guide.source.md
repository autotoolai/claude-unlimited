## 与已有文章的边界

`claude-code-make-video`（Remotion 八步教程，start 分类）讲的是从零跑通第一条 MP4：装 Node.js 与 FFmpeg、建项目、装技能、导出。本文讲的是路已经跑通之后的选型与迭代：四个技能横向对比、素材准备、配音路线、三轮迭代的踩坑。两篇 related 互指，正文不重复步骤。

# Claude 桌面版教程：新增供应商、开启路由与安装

> **一句话答案**：Claude 桌面版要用 CC Switch 新增一个「桌面版」供应商，接入方式选直连，填上接口地址与 API Key，再打开路由开关并启用检测，最后安装桌面版客户端即可。

桌面版要多建一个供应商并打开路由，这一页把它和客户端安装一起讲完。

## 1. 安装 CC Switch

装好 CC Switch 就算准备好了一半：它是个专门管 API 配置的小工具，全程默认安装。

### 挑对系统的安装包

装完先别动配置，下一步才需要填值。

- 打开下面的官网 → 下载 Windows 或 macOS 版 → 双击运行，一路默认。

## 2. 换取 API Key

卡密在发货信息里，到 rsxermu666.cn（管理后台）换成一把 sk- 开头的 API Key，后面全程只用它。

### 把卡密换成 API Key

后面每一步都要填这把 Key，别提前改。

- 打开下面的管理后台 → 在「我的面板」或「提取 Key」页面粘贴激活码 → 提交激活 → 复制拿到的 Key。

注意：
- 激活码、API Key、用量记录都存在后台里：换设备、换浏览器都不影响，忘了就回后台用同一把激活码再看。
- 主域名打不开时，用后台里的备用域名（bxcv.store），API Key 不用换。

## 3. 新增桌面版供应商

桌面版在 CC Switch 里是一个单独的供应商条目，要自己新建，不能用一键导入。

### 切到桌面版的配置

桌面版和 Claude Code 是两套配置，切错了会改到别的客户端。

- 打开 CC Switch → 点顶部应用栏里带显示器角标的那个图标 → 列表里出现「Claude Desktop Official」就对了。

### 自己建一条配置

预设都是别家服务，本卡要自己填。

- 点右上角橙色「+」→ 在「添加新供应商」页的预设列表里选「自定义配置」。

## 4. 填入接口地址与 API Key

地址填管理后台首页那一行，Key 填上一步换来的那把，接入方式选「直连」——桌面版和 Claude Code 的区别就在这里。

### 填三个值

填错的表现是连不上或报鉴权错误。

- 请求地址填 https://rsxermu666.cn（不要带 /v1 结尾）
- API Key 填上一步换来的 sk- 开头那把
- 接入方式选「直连」

## 5. 打开路由开关

桌面版必须走本地路由转发，请求才会被送到网关——这一步不做，前面配的全都白配。

### 打开两个开关

总开关和应用开关缺一个，请求都不会被转发。

- CC Switch → 设置 →「路由」→ 打开「路由总开关」→ 在「路由启用」里打开「Claude」。

### 确认路由已生效

看到这个标记，才说明请求会走本地转发。

- 回到 CC Switch 主界面，这条配置名字旁边有蓝色小标「需要路由」。

## 6. 启用并检测链路

配完最后启用一下，检测显示连通正常，桌面版就能用了。

### 让配置生效

不启用的话配置不会写进客户端。

- 回到 CC Switch 主界面 → 点「启用」→ 再点「检测链路」，弹出「连通正常」即可。

## 7. 安装 Claude 桌面版

配置好了，再装桌面版客户端本体，两个下载渠道都放这儿。

### 装官方客户端

客户端本体是官方的，和前面的 API 配置是两件事。

- 打开下面的下载页 → 选自己的系统 → 下载后双击安装。

## 8. 在桌面版里开始用

打开就能用，桌面版和终端里用的是同一把 Key、同一个模型。

### 打开 Claude 桌面版，直接开始对话

验证整条链路：能正常回答、模型对得上，就说明配成了。

- 打开桌面版 → 随便问一句（比如「你是什么模型」），能正常回答就是配好了。

## 9. 提示要虚拟机平台怎么办

这是 Windows 缺可选功能，和你的 API 配置无关，按系统提示开一下就好。

### 认出这个报错

先分清是系统功能缺失还是配置问题，这一屏的报错只跟系统有关。

- 弹窗里写着 requires the Virtual Machine Platform on Windows，就是这个问题，API 配置不用动。

### 打开功能面板

这个功能在系统设置里，不在 Claude 里面。

- 打开 Windows 搜索框 → 输入「启用或关闭 Windows 功能」→ 打开它。

### 勾选两项并重启

两个都勾上，桌面版的代码与文件功能才完整可用。

- 在列表里勾选「虚拟机平台」和「适用于 Linux 的 Windows 子系统」→ 确定 → 重启电脑。

## 常见问题

### Claude 桌面版怎么用 Claude 无限卡？

在 CC Switch 里新增一个供应商，选择 Claude 桌面版并用自定义配置，接入方式选直连，填入接口地址与 API Key，打开路由总开关和「路由启用」里的 Claude 开关，启用并检测链路后安装桌面版即可。

### 桌面版和 Claude Code 用的地址一样吗？

一样，都是管理后台首页那一行地址。区别在接入方式：桌面版选「直连」，Codex 要选 Anthropic Messages 上游格式。

### 桌面版提示要 Virtual Machine Platform 怎么办？

这是 Windows 的可选功能没开。搜索「启用或关闭 Windows 功能」，勾选「虚拟机平台」和「适用于 Linux 的 Windows 子系统」，重启电脑即可。

### 桌面版打不开、显示不可用？

通常是配置还没写进客户端。把 Claude 桌面版完全退出（不是最小化），回到 CC Switch 确认配置已启用、路由已打开，再重新打开。

# 使用教程（仓库副本）

> 从换取 API Key 到检测链路，选你的客户端照着做就行。Claude Code 插件、Claude Code CLI、Claude 桌面版、Codex、WorkBuddy、Cursor 各有一条完整路径，每步都有真实截图，不用先懂原理。

本目录是官网[使用教程](https://claude-unlimited.aiautotools.com/guide)的仓库副本：同一份正文与真实截图说明。

## 选择一条路径

- [Claude Code 插件](cc.md)：同一款 Anthropic 官方插件，VS Code 和 Cursor 都能装。图形界面用，比命令行更好上手。（10 步 · 一键导入）
- [Claude Code CLI](cli.md)：终端里的 Claude Code。官方脚本装 CLI，两个环境变量接上网关，装完就能直接用。（9 步 · 装 CLI + 变量）
- [Claude 桌面版](desktop.md)：桌面版要单独建一个供应商并开路由，比 Claude Code 多两步。装完桌面版客户端即可用，也不用翻墙。（13 步 · 新增供应商）
- [Codex](codex.md)：Codex 多两个关键动作：上游格式必须选 Anthropic Messages，配置完必须彻底重启 Codex 才会生效。（11 步 · 新增供应商）
- [WorkBuddy](workbuddy.md)：最省事的一条路，不用装 CC Switch，也不用开路由。三个值填进 WorkBuddy 的自定义模型里就行。（3 步 · 自定义模型）
- [其它客户端](cursor.md)：已经会自己填 API 的人看这一页：三个值怎么填、各客户端的差异，一次说清。（三个值 · 两张速查表 · 手动填值）
